# OmniVoice Cloud API — Deployment Guide

This guide details the step-by-step process for deploying the **OmniVoice Cloud API** across **Oracle Cloud VPS**, **RunPod Pods**, and **Cloudflare R2**.

---

## Architecture Overview

1. **Oracle Cloud VPS**: Runs the public FastAPI API Gateway behind Nginx HTTPS.
2. **RunPod GPU Pod**: PAYG GPU container running `OmniVoice` with PyTorch & CUDA.
3. **Cloudflare R2**: Object storage for temporary audio files (`reference/` and `generated/`) with 24-hour auto-expiration lifecycle rules.

---

## Step 1: Cloudflare R2 Bucket Setup

1. Log into your **Cloudflare Dashboard** and navigate to **R2 Object Storage**.
2. Click **Create Bucket** and name it `omnivoice-audio`.
3. Go to **Bucket Settings** -> **Object Lifecycle Rules** -> Add Rule:
   - **Rule Name**: `Auto-delete 24h`
   - **Prefix**: Leave empty (applies to all objects in `generated/` and `reference/`)
   - **Action**: Expire objects after **1 day (24 hours)**.
4. Go to **Manage R2 API Tokens** -> **Create API Token**:
   - Permission: `Object Read & Write`
   - Copy `Access Key ID`, `Secret Access Key`, and your account S3 endpoint URL: `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`.

---

## Step 2: Deploy GPU Pod on RunPod (PAYG)

1. Log into **RunPod.io** -> **Pods** -> **Deploy New Pod**.
2. Select a GPU with at least **16 GB VRAM** (e.g., RTX 4090, RTX 3090, or A10G).
3. Set Template / Docker Image:
   - Use custom Docker image: `your-dockerhub/omnivoice-gpu:latest`
   - Or build image from `./gpu_pod/Dockerfile`.
4. Configure Container Environment Variables:
   - `MODEL_CACHE_DIR=/models/omnivoice`
   - `CUDA_VISIBLE_DEVICES=0`
   - `TORCH_DTYPE=float16`
5. Expose HTTP Port **8000** for HTTP proxy.
6. Once deployed, note down your RunPod proxy URL:
   `https://<POD_ID>-8000.proxy.runpod.net`

---

## Step 3: Oracle Cloud VPS API Gateway Setup

1. SSH into your **Oracle Cloud Always Free VM** (Ubuntu 22.04 LTS).
2. Install Docker & Docker Compose:
   ```bash
   sudo apt-get update
   sudo apt-get install -y docker.io docker-compose curl git
   sudo systemctl enable --now docker
   ```
3. Clone project repository to Oracle VM:
   ```bash
   git clone https://github.com/your-username/omni-clone.git
   cd omni-clone
   ```
4. Copy environment configuration:
   ```bash
   cp .env.example .env
   ```
5. Edit `.env` with your real keys:
   ```env
   API_KEY=my_ultra_secure_api_key_123
   JWT_SECRET=my_jwt_secret_key_456
   
   RUNPOD_API_ENDPOINT=https://<POD_ID>-8000.proxy.runpod.net
   RUNPOD_API_KEY=your_runpod_api_key
   
   R2_ENDPOINT=https://<ACCOUNT_ID>.r2.cloudflarestorage.com
   R2_BUCKET=omnivoice-audio
   R2_ACCESS_KEY=your_r2_access_key
   R2_SECRET_KEY=your_r2_secret_key
   ```
6. Launch Docker Compose Stack:
   ```bash
   sudo docker-compose up -d --build
   ```

---

## Step 4: Verification & Testing

Run the automated integration test script from any computer or terminal:

```bash
export API_BASE_URL="http://your-oracle-vps-ip"
export API_KEY="my_ultra_secure_api_key_123"

python3 scripts/test_api.py
```

Expected Output:
- ✅ Health status `200 OK`
- ✅ Reference audio uploaded to R2 (`reference/ref_xxx.wav`)
- ✅ Zero-shot TTS generated by RunPod OmniVoice GPU
- ✅ Download URL presigned by Cloudflare R2 verified
